# Email Marketing Studio

This is a practice project from an AI engineering course. It shows how to plan and write email campaigns with Claude Code.

**Everything here is for practice.**

- All the people in `leads/leads.csv` are made up. None of them are real.
- Their email addresses use `example.com`, which can never receive mail.
- The emails in `campaigns/` are drafts only. None have been sent.

## Folders

- `brand/` holds the voice guide that every email follows.
- `leads/` holds the made-up lead list and its rules.
- `campaigns/` holds campaign plans and the emails written for each one.
- `notes/` holds research and decisions about how the studio works.
- `.claude/` holds the email rules and the `personalize` skill.
