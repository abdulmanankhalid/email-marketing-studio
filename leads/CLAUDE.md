# Leads Folder Rules

These rules apply to the files in `leads/` only.

- Everyone in this folder is a made-up practice person. None of them are real.
- Never add real people or real email addresses.
- Every row needs a value in the `consent` column. Don't leave it empty.
- Never change the `@example.com` email addresses. That domain is reserved and can never receive mail, so no real person is ever emailed.
